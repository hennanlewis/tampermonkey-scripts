# Tampermonkey Scripts

Coleção de scripts para automatizar tarefas e melhorar a experiência em sites usando o Tampermonkey.

## Requisitos

- Navegador compatível:
  - Google Chrome
  - Microsoft Edge
  - Firefox
- Extensão:
  - :contentReference[oaicite:0]{index=0}

## Instalação

1. Instale o Tampermonkey no navegador.
2. Abra o painel da extensão.
3. Clique em **Create a new script**.
4. Cole o conteúdo do script.
5. Salve usando `Ctrl + S`.
